# 0002 Preserve Image URL At Wire Protocol Boundary

Native Protocol request items should preserve Codex's `Image URL` at the Wire Protocol boundary instead of forcing core to convert images into provider-specific inline payloads. `core` should map `ContentItem::InputImage { image_url, .. }` to a provider-neutral image item. The Wire Protocol should provide an `Image URL Parser` for shared classification, and provider adapters should use it before producing Anthropic or Gemini image payloads. This keeps core from fetching, reading, or parsing image references while still avoiding duplicated data URL parsing in each adapter. Native Protocol v1 should support inline image data URLs through that parser and return clear unsupported-image errors for unsupported Image URL forms.
